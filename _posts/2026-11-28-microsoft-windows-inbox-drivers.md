---
title: "微软推进以 Windows 内置驱动取代部分第三方驱动"
date: 2026-11-28
tags: [Windows, Microsoft, 驱动, 系统安全]
---

微软正在推动以 Windows 内置驱动取代更多第三方设备驱动，目标是减少进入系统内核的第三方代码，从而改善系统稳定性与安全性。

在 Ignite 2026 大会上，微软确认正在为整类硬件开发新的基础驱动，让更多设备可以直接依靠 Windows 自带驱动运行。打印机是首批重点，近期推出的 Windows Ready Print 模式旨在取代传统第三方打印驱动。

Windows 产品经理 Mehmet Kucukgoz 表示，SoundWire、SDCA 等音频类驱动很快将成为 Windows 内置组件。I3C 总线、USB 以太网以及 MIPI 摄像头类驱动也在开发中。

此外，微软近期在 Windows 硬件工程大会上推出驱动质量倡议（Driver Quality Initiative，DQI），以提高 Windows 驱动在可靠性、质量和安全方面的标准。微软也鼓励第三方开发者优先使用 Windows 已有的内置驱动，OEM 为特定硬件开发的定制驱动同样需要遵循这一方向。

减少第三方代码进入内核，有望降低驱动冲突、系统崩溃和安全风险。不过，这并不意味着第三方驱动会立即消失，专业设备和特殊硬件仍可能需要厂商提供专用驱动。
